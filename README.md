# Literasi Aksara

Literasi Aksara adalah aplikasi berita lintas platform yang dibangun menggunakan Flutter. Aplikasi ini menyediakan antarmuka yang bersih untuk membaca berita terbaru dan dilengkapi panel manajemen untuk admin.

## 📜 Deskripsi

Proyek ini merupakan aplikasi klien berita yang mengambil data dari API eksternal. Aplikasi ini mengimplementasikan sistem otentikasi pengguna lokal yang membedakan antara dua peran: **Admin** dan **Pembaca (Konsumen)**.

-   **Pembaca** dapat menjelajahi, mencari, dan memfilter berita berdasarkan kategori.
-   **Admin** memiliki hak akses penuh untuk melakukan operasi Create, Read, Update, and Delete (CRUD) pada artikel berita melalui halaman manajemen khusus.

Aplikasi ini dibangun dengan state management menggunakan `provider` dan dirancang untuk dapat dijalankan di berbagai platform seperti Android, iOS, dan Web.

## ✨ Fitur

-   **Otentikasi Lokal**: Sistem login dan registrasi dengan penyimpanan akun di perangkat.
-   **Dua Peran Pengguna**:
    -   **Admin**: Mengelola penuh artikel berita (CRUD).
    -   **Pembaca**: Hanya dapat membaca berita.
-   **Tampilan Berita**: Menampilkan daftar berita dalam bentuk kartu yang informatif dan mudah dibaca.
-   **Filter & Pencarian**: Pengguna dapat memfilter berita berdasarkan kategori dan melakukan pencarian berdasarkan judul.
-   **Manajemen Berita (Admin)**: Antarmuka untuk menambah, mengedit, dan menghapus berita.
-   **Lintas Platform**: Dibangun dengan Flutter untuk portabilitas ke berbagai platform.
